# مجلد الصور

حط صورك هون **بنفس الأسماء** بالضبط، وبتظهر بالموقع تلقائياً.
إذا ملف مش موجود، الموقع بيعرض صورة احتياطية من الإنترنت لحتى ما يبيّن فاضي.

| الملف | وين بيظهر | المقاس المقترح |
|---|---|---|

**اللوغو** (بمجلد `logo/`):
- `logo-light.png`: اللوغو الكامل بخط أبيض، للخلفيات الغامقة (بالفوتر).
- `logo-mark.png`: الرمز لحاله (بالقائمة فوق).
- `favicon.png`: أيقونة التبويب.
- `logo-original.png`: الملف الأصلي.

**ملاحظات:**
- لتغيير الأسماء أو النصوص أو إضافة سلايد/كرت جديد: عدّل ملف `js/data.js`.
- بدل ملف الفيديو بتقدر تحط رابط يوتيوب بـ `promoVideo` بنفس الملف.
- خفّف حجم الصور قبل الرفع (مثلاً على squoosh.app)، الأفضل تحت 400KB للصورة.
